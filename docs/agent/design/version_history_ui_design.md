# 版本历史（Version History）极简设计规范

## 1. 事实来源与现状诊断

- **文档定位**：桌面端文档历史快照（Snapshot）检视、Visual Diff 对比与安全回滚界面的视觉与交互规范。
- **关联文件**：`apps/desktop/src/components/history/HistoryDrawer.tsx`、`apps/desktop/src/components/history/line-diff.ts`
- **问题诊断（针对上一代实现的用户反馈）**：
  1. **macOS 交通灯冲突**：在沉浸式/Overlay 标题栏模式下，历史抽屉顶部直接顶格渲染，导致 macOS 窗口红黄绿交通灯直接压在「⏰ 版本历史」标题上，破坏桌面原生质感。
  2. **过度卡片化（卡片臃肿）**：左侧时间轴列表采用电商卡片式设计（带厚边框、内外多重内边距、分割线与「正在检视 ->」跳转文字），单条高度超过 100px，一屏仅能展示 2~3 个快照，信息密度极低。
  3. **双层 Header 冗余与“AI 味”图例**：顶部堆叠了两层工具栏，并带有 `🟢 快照内容 (恢复时找回) 🔴 当前修改 (恢复时替换)` 的说教式文案，视觉噪音大且侵占内容高度。
  4. **空状态生硬**：与当前完全一致时仅输出一串生硬的居中文本，缺乏优雅的空状态表达。
  5. **键盘漫游缺失**：不支持方向键切换快照，无法通过键盘高效对比版本演进。

---

## 2. 核心设计原则：Less, but better

1. **去卡片化（List over Cards）**：时间轴回归 macOS 原生边框精简列表，单行高度收敛至 44~48px，呈现清晰的「相对时间 + 精确时刻 + 字符数 + 触发类型」。
2. **单一整合工具栏（Unified 44px Toolbar）**：合并双层工具栏为单层，采用 Apple 风格的胶囊分段控件 `[ 对比 | 预览 ]`，彻底移除解释性颜色图例（Diff 红绿配色属于通用常识）。
3. **居中浮动工作台（Centered Sheet Modal）**：脱离侧边推拉抽屉模式，采用居中圆角浮层（`w-[min(920px,94vw)] h-[min(620px,85vh)]`），自带安全边距，从根本上杜绝 macOS 交通灯碰撞。
4. **键盘优先（Keyboard First）**：支持 `↑` / `↓` 键平滑漫游所有快照版本，`Esc` 一键返回编辑画布。
5. **精准选区保护**：时间轴与行号元信息严格禁止选中（`select-none`），正文与 Diff 代码支持精确高亮复制（`select-text`）。

## 3. 信息架构与视觉层级

```
+-----------------------------------------------------------------------------------+
|  版本历史 [2]       10/26 16:34:05  +12 -4      [ 对比 | 预览 ]   [复制] [恢复此版本] [✕] | <- 单一 44px 工具栏
+--------------------+--------------------------------------------------------------+
| 5 分钟前    保存   | 1  1    import { ... }                                       |
| 16:34:05   834字   | 2    -  const oldConfig = ...;                               |
|--------------------|    2 +  const newConfig = ...;                               |
| 2 小时前    自动   | 3  3    export function ...                                  |
| 14:12:00   820字   |                                                              |
|                    |                                                              |
|                    |                                                              |
+--------------------+--------------------------------------------------------------+
  左栏：极简时间轴 (260px)    右栏：Visual Diff / 源码预览画布 (flex-1)
```

## 4. 关键组件与交互细节

### 4.1 居中浮层容器
- **尺寸**：`w-[min(920px,calc(100vw-32px))]`，`h-[min(620px,calc(100vh-48px))]`，圆角 `rounded-2xl`，微投影 `shadow-2xl`。
- **避让保障**：无论小窗口还是大窗口，上下左右始终保留安全留白，绝不遮挡 macOS 窗口原生控件。
- **遮罩材质**：`bg-black/40 backdrop-blur-[4px]`，聚焦当前对比任务。

### 4.2 统一工具栏（Header）
- **左侧**：标题「版本历史」采用 13px font-semibold，跟随紧凑的快照数量 Badge。
- **中间**：呈现选中快照时间与 Diff 统计（如 `+12 -4` 或「与当前一致」浅色胶囊）。
- **右侧**：
  - 胶囊分段切换器：`[ 对比 | 预览 ]`，高质感小滑块效果；
  - 辅助动作：`复制全文`（次级按钮或复制图标）；
  - 主操作：`恢复此版本`（Primary 强调色药丸按钮）；
  - 关闭：简洁 `✕` 图标按钮。

### 4.3 时间轴列表（Timeline List）
- **单项布局**：
  - 第一行：相对时间（如「刚刚」、「5 分钟前」、「昨天」）+ 极简浅色触发标签（「保存」/「自动」/「回滚」）；
  - 第二行：精确时间（`16:34:05`，等宽字体）+ 字符体量（`834 字`）。
- **状态表达**：
  - 选中项：采用 `var(--theme-control-active)` 柔和背景底色与微加粗文字，摒弃刺眼的强行亮蓝描边；
  - 悬浮项：`hover:bg-[var(--theme-control-hover)]` 细腻渐变过渡。

### 4.4 差异对比与空状态（Diff Canvas）
- **一致状态**：淡绿色微勾图标 + 「内容完全一致」与「当前编辑器内容与该快照无行级修改」引导。
- **变更行着色**：
  - 新增行：`bg-emerald-500/[0.08]`，标号 `+` 为祖母绿；
  - 删除行：`bg-rose-500/[0.08]`，标号 `-` 为柔和玫瑰红；
  - 双列行号 Gutter（当前行号 | 快照行号），等宽右对齐，低饱和度展示。
