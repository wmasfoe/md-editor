# Changelog

## 0.22.0 - 2026-11-09

- 新增写作偏好（首版）：可以从你打开过的工作区里学习写作习惯，并在续写与语法修复时使用。
  - 默认关闭；学习只用本地 Standard 模型，历史文章不会上传。
  - 空闲时以可抢占的后台任务静默进行，不影响打字；没装 Standard 时提示「风格学习仅支持端侧模型」并给出下载入口。
  - 画像分三层：你手写的偏好 > 当前工作区画像 > 全局画像，按维度逐级覆盖。
  - 规则用「偏好简短段落」这类直白文字展示，每条都能查看来源文章并点击打开。
  - 支持「撤销找回」与「清除学习数据」。
- 新增「不参与风格学习」：在文件树右键把文件或目录排除，排除后立即生效。
  - 不写入任何工作区文件（不再使用 .aiignore）。
  - 被排除的文件只出现在「已排除」列表，不再计入参与学习的文章。
- 新增偏好跟随目录：目录被移动或改名后，按内容自动找回，成功会提示且可撤销。
- 优化规则生效节奏：规则要多轮学习一致才会生效，偶然的写法不会立刻影响输出。
- 优化学习素材的判断：采纳 AI 建议后你又做的修改会作为偏好的补充证据；采纳的 AI 文字本身会被排除，不会被当成你的风格。
- 语法修复与偏好分开标注：你的书写习惯不会被判为错误，风格统一建议单独标注为「风格」，与「修正」分开。
- 隐私边界：画像与学习数据只保存在本机；云端续写使用偏好需要单独授权，只发送规则文字，不发送历史文章；Lite 模型不使用偏好。

## 0.19.0 - 2026-11-01 (#205, #206, #207, #208)

- 新增经典纸墨「Kami」主题与三层样式引擎：新增极简宣纸质感的「纸墨 (Kami Light)」与夜间「墨色 (Kami Dark)」内置主题，重构样式系统为基础、主题与用户自定义三层覆盖引擎，选区采用半透明水墨微蓝高光并满足 WCAG 2.1 AA/AAA 对比度标准。

- 优化字体与排版设置实时跨窗口预览：外观设置中切换正文字体、代码字体或字号调整时，主编辑窗口即时无缝预览效果；取消设置自动回滚，保存时即刻持久化。

## 0.18.0 - 2026-10-28 (#202)

- 新增 Markdown 规范检查 (Lint)：集成基于 markdownlint 的实时格式检查与波浪下划线标记；支持悬停查看说明与单项快速修复，按下 ⌥⇧L 打开底部诊断面板，支持 ⌥⇧F 一键批量自动修复常见排版问题（支持中、英、日、繁体多语言实时切换）。
- 新增高质量 HTML 与 PDF 导出：标题栏新增快捷导出入口，支持导出为保留完整主题样式（含代码高亮、数学公式与 Mermaid 图表）的独立 HTML 文件或原生矢量分页 PDF，同时支持直接复制富文本 HTML 至剪贴板。
- 优化设置面板：重构设置架构，分类更清晰；新增独立的「快捷键设置」，支持自定义 Markdown 检查与一键修复快捷键，并提供一键恢复默认。
