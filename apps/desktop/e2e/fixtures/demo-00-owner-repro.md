> 每个功能都是"文件 → 步骤 → 预期"的结构，照着按就行。

3. 两个约定：
   - **Mod** 在 macOS 上是 `Cmd(⌘)`，其他平台是 `Ctrl`。
   - 所有演示都在 **WYSIWYG 模式**下进行（源码模式下块命令语义相同，但演示以所见即所得为准）。

## 1. 命令面板（先学会这个，后面全靠它）

按 **`Mod+K`**（macOS 上是 `Cmd+K`），在"命令搜索"框里输入下面这些**英文名**
（块命令也支持中文关键词，比如搜"块 上移"）：

| 输入 | 得到 |
| --- | --- |
| `Focus Mode` | 开关专注模式 |
| `Typewriter Mode` | 开关打字机模式 |
| `Move Block Up` / `Move Block Down` | 上移 / 下移光标所在块 |
| `Duplicate Block` | 在下方复制一份当前块 |
| `Delete Block` | 删除当前块 |

> 背景：`Mod+K` 现在归命令面板独占（编辑器里原来的同名绑定已让位，不会再双触发）。

## 2. Tab 统一仲裁（`demo-01/02/03`）

原则只有一条：**按 `Tab` 时，编辑器按固定优先级只做一件事** ——
AI 建议接受（需配 AI）> **括号/链接跳出** > 代码块结构缩进 > **表格跳到下一格**。
以前这几套逻辑各管各的会打架，现在收敛到同一个决策函数。

### 2.1 括号与链接跳出（`demo-01`）

| 试 | 预期 |
| --- | --- |
| `foo()`，光标放进括号里按 `Tab` | 一步跳到 `)` 外面 |
| `[待办事项]`，括号里按 `Tab` | 跳到 `]` 外面 |
| `[TypeSafe 官网](https://example.com)`，光标先后放在 `]` 内和 `()` 内按 `Tab` | 连续按几次，逐步跳出整段链接 |
| `Foo_(bar)` 这类行尾括号 | `Tab` 把整段当作一个单位跳过 |
| `（中文括号内容）` | 全角括号同样跳出（中英文混排已处理） |
| `outer(inner())`，光标在最内层 | **从最内层逐层跳出** |
| 一个裸 URL（如 `https://example.com/some/path`），光标在网址里 | 整段 URL 被当作一个单位跳过 |
| `foo(\))`（被反斜杠转义的括号） | **不跳出**（fail-closed：宁可不动，不乱跳） |

### 2.2 表格单元格（`demo-02`）

1. 点进任意单元格，顺手打一个字。
2. 按 `Tab`。

预期：**你刚打的字被原样提交（内容零变化），光标跳到下一格**。
这是专门锁定的行为：Tab 先做"括号跳出判断"，再跳格，最后才落盘输入。

### 2.3 代码块与边界（`demo-03`）

- 围栏代码块里按 `Tab`：按缩进层级结构化缩进（不是瞎插空格）。
- 缩进代码块里同理。
- 把光标放进**最顶部 frontmatter 区**或 **HTML 注释块**里按 `Tab`：**不会**触发任何跳出，
  就是普通缩进 —— 预期：和 frontmatter 一样，`Tab` 只是普通缩进。

```js
console.log('123');
```

### 2.4 中文输入法（任意文件可试）

切到中文输入法，打几个拼音**停在组词状态**（候选词还没上屏），按 `Tab`：
预期是**原生行为**（上屏/选词），编辑器不会抢 Tab 去做括号跳出。
（背后是三道门：浏览器组合标志、编辑器组合态、选区护栏，任意一道开着就放行。）

## 3. 专注模式 / 打字机模式（`demo-04`、`demo-06`）

打开方式三选一：菜单栏"视图"里两个**可独立勾选**的菜单项；
或命令面板搜 `Focus Mode` / `Typewriter Mode`；
或快捷键 **`Cmd+Alt+F`（专注）** / **`Cmd+Alt+Y`（打字机）**。
两个模式**可以叠加**（这正是它们做成两个独立勾选项的原因）。

### 3.1 专注模式（`demo-04`）

1. 打开 `demo-04`，把光标放到"普通段落甲"里，打开专注模式。
2. 预期：**只有光标所在的块完全不透明**，其余块被压暗（默认不透明度 0.38）。
3. 按 `↓` 把光标挪到下一块：压暗跟着光标走。
4. 重点看这几个"整块组件"：setext 标题、引用定义、脚注定义、表格、分割线——
   **它们一个都不会消失**，不活动时照样被正常压暗（只是压暗方式是切整个块的根样式，而不是逐行）。

### 3.2 打字机模式（`demo-06` 长文）

1. 打开 `demo-06`（60 段长文），打开打字机模式。
2. 按 `Cmd+End` 跳到文末：预期光标被**校正到视口约 50% 高度**（而不是贴底）。
3. 在小范围内上下移动：**不滚动**（偏离小于 0.35 倍视口高度时保持不动，防抖）。
4. 打字：光标**立刻**跟随居中，没有平滑滚动的"飘"感。

### 3.3 可调项

专注压暗强度默认 0.38，允许范围 `[0.30, 0.50]`（另有 facet/选项可配，超界会被夹回）。

## 4. 块操作（`demo-05`）

打开 `demo-05`，把光标放到任意一块里（标题、段落、列表项、任务项、代码块、引用、分割线、表格都行）：

| 命令面板输入 | 预期 |
| --- | --- |
| `Move Block Up`（或搜"块 上移"） | 整块和上一块交换位置；已在顶部则无操作 |
| `Move Block Down`（或搜"块 下移"） | 整块和下一块交换位置；已在底部则无操作 |
| `Duplicate Block`（或搜"块 复制"） | 在下方插入一份完整拷贝 |
| `Delete Block`（或搜"块 删除"） | 删除整块 |

注意两点：
- **一次只操作光标所在的块**（多选块暂不支持，这是明确降级的范围）。
- 表格、分割线这类"整块组件"会**整体**移动/复制/删除，不会被拆散。
- 标题和有子项的列表旁边有**折叠按钮**，点一下可以折叠/展开下方内容。

## 5. 不在演示范围的东西（诚实清单）

- **搜索命中在压暗块里的对比度**：有样式兜底，但按计划是显式延期的验证项，别拿它当验收标准。
- **多选后批量移动块**：不支持（计划里唯一明确降级项）。
- **视图模式的快捷键自定义**：`Cmd+Alt+F/Y` 目前是菜单内建值，设置里改键还不会跟随菜单（已登记为后续项）。
- **源码模式**：块命令语义与 WYSIWYG 一致（同一份解析），演示仍以 WYSIWYG 为准。
